# Y

**Curiosity moves you forward. Slowly.**

The brainchild invention of Avie Abell of Knoxville, Tennessee.

Y is the world's first Slow-Thinking AI. You ask Y anything, and Y answers
with a better question. Usually "Why?"

Live at **[ytho.co](https://ytho.co)**.

## What this is

A parody product page, built around a logo Avie drew: a lime-green snail
whose shell spirals into a lowercase `y`, with a question mark over its head.
The company is imaginary. The curiosity is not.

## Layout

| path | what |
| --- | --- |
| `index.html` | the whole page, no build step |
| `assets/` | the logo cropped from Avie's brand sheet, plus generated illustrations |
| `vercel.json` | static hosting, nothing to compile |

Open `index.html` in a browser to work on it. There is no toolchain.

## Notes

Asset paths are absolute (`/assets/...`) so the page renders the same whether
it is reached with or without a trailing slash.
